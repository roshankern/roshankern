### Hi there 👋

I'm Roshan. I use computation to study and improve biology, and I care about health, technology, and animals.

- 🎓 I'm a PhD student in Biological Engineering at **MIT** (2026–).
- 🧬 I most recently built **[PWPA](https://github.com/roshankern/prior_weighted_partner_average)**, a model that predicts how cells respond to gene knockdowns no one has measured yet.
- 🔭 Before that, I co-developed **[Brieflow](https://github.com/cheeseman-lab/brieflow)** and co-founded the computational team at the [Cheeseman Lab](https://cheesemanlab.wi.mit.edu/) (Whitehead Institute, MIT).

#### 🛠️ Open-source work

| Project | What it does |
|---|---|
| [**PWPA**](https://github.com/roshankern/prior_weighted_partner_average) (2026) | Prior-Weighted Partner Average: predicts responses to an unmeasured knockdown from knockdowns measured in the same cell context, plus gene–gene priors drawn from many datasets. Beats PIE on PIE's own benchmark (AUPRC 0.325 vs. 0.304) with less compute and more interpretable output. Built with an LLM-driven lab loop of ~580 runs. |
| [**Brieflow**](https://github.com/cheeseman-lab/brieflow) (2025) | Extensible pipeline for optical pooled screen data. Cut screen configuration time by 80% and module integration time by 93%. [*Nature Communications*](https://doi.org/10.1038/s41467-026-73643-7) · [Featured by Anthropic](https://anthropic.com/news/accelerating-scientific-research) · MIT Prize for Open Data |
| [**Pycytominer**](https://github.com/cytomining/pycytominer) (2025) | Functions for processing high-dimensional cell experiment readouts. [*Nature Methods*](https://doi.org/10.1038/s41592-025-02611-8) |
| [**IDR Stream**](https://github.com/WayScience/IDR_stream) (2023) | Pipeline that turns Image Data Resource cell images into single-cell features. |
